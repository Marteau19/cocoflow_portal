# Ecoflo Portal, all interface copy

Generated by `scripts/export-copy.mjs` from the running app, so every date, count
and interpolated sentence appears as a reader sees it rather than as a template.

Organised by role, then by screen, then by band in reading order. Band kinds are
the composition types from `DESIGN.md` section 2: `masthead` is the dark opening
field, `data` and `rail` carry the rows, `closing` is the note at the foot.

Mock content from `seedData.ts` (customer names, addresses, identifiers, figures)
is included because it is on screen, but it is marked as data in
`COPY-strings.csv` and must not be translated.

### Navigation labels

Mirrored from `src/shell/roles.ts`. These are the only words in the shell that
change per role, and they are what a customer taps, so they carry more weight per
character than anything else in the product.

- **Client, before install**: Start, Request, Quote, Project
- **Client, system owner**: Home, System, Shop, Account
- **Service Point, technician**: My day, Route, Flo
- **Service Point, manager**: Dashboard, Dispatch, Customers, Leads, MARCOM, Inventory, Team, Flo
- **PTWE Global**: Network, Mix tracker, Adoption, Benchmarking, Readiness
